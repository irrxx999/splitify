# Splitify — бот подсчёта долгов в путешествии

## Что нужно установить (один раз)

1. **JDK 17+** — https://adoptium.net (Temurin, при установке отметь "Add to PATH")
2. **Maven** — https://maven.apache.org/download.cgi (распаковать, добавить `bin` в PATH)

Проверка в командной строке:

```
java -version
mvn -version
```

## Получить токен бота

1. В Telegram найди **@BotFather**
2. Команда `/newbot`, придумай имя и username (должен кончаться на `bot`)
3. BotFather выдаст токен вида `123456789:AAE...` — скопируй его

Токен — это пароль от бота, не выкладывай его никуда.

## Собрать и запустить (Windows)

```bat
cd D:\Splitify
mvn clean package

set BOT_TOKEN=сюда_вставь_токен
java -jar target\splitify.jar
```

Если в консоли появилось `Splitify запущен` — открывай бота в Telegram и пиши `/start`.

Рядом с проектом появится файл `splitify.db` — это вся база. Бэкап = просто скопировать файл.

## Команды бота

```
/newtrip Таиланд EUR      — поездка + базовая валюта
/add Аня RUB              — участник + валюта возврата долгов
/rate THB 0.026           — курс: 1 THB = 0.026 EUR
/spend Аня 3000 THB ужин  — трата (делится на всех)
/spend Аня 3000 THB ужин | Петя, Маша  — делится только на перечисленных
/list                     — список трат
/total                    — итог: кто, кому, сколько
/close                    — закрыть поездку
```

## Пример сценария

```
/newtrip Таиланд EUR
/add Аня RUB
/add Петя EUR
/add Маша EUR
/rate THB 0.026
/rate RUB 0.010
/spend Аня 3000 THB ужин
/spend Петя 90 EUR отель
/total
```
